# UMER PORTFOLIO — V7 EXPERIENCE UPGRADE

Built on the V6 modular static architecture.

## New systems
- Project Universe: data-driven spatial project field using the same project data as the Holo Deck.
- Build Mode: engineering lens with project problem, solution, stack signals and media preview.
- The Lab: particle field, type reactor and color reactor.
- Black Room: hidden layer opened with `B`.
- World atmosphere: section-aware spectral accent changes.
- Rich project case-study modal with image/video preview.
- Expanded command palette + tour + section rail.

## Preserved
- Circular hero artwork and removed hero glitch/click distortion.
- PRISM NEBULA theme.
- Nova-AI and StudyFlow-AI local builds and media.
- Holo Deck and Transmission Deck.
- Existing story, commerce, transformation and contact content.

## Deployment
The project remains framework-free and uses classic script files so it can still be opened from `index.html`. It can also be deployed to Vercel as a static site.
